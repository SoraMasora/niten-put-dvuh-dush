# NITEN: ПУТЬ ДВУХ ДУШ
## Полный GDD / Мега-промт для Onimusha-like игры с двумя катанами
**Жанр:** кинематографичный самурайский survival-action / hack-and-slash
**Референсы:** Onimusha: Warlords (2001), Onimusha 3, Sekiro, Nioh, Ghost of Tsushima
**Движок:** Unreal Engine 5.5+, Nanite + Lumen
**Платформы:** PC / PS5 / Xbox Series
**Тон:** мрачный, мистический, кроваво-красивый. Грязь, пепел, кровь-лепестки, буддийский хор.
**Длительность:** 12-15 часов. 5 глав + пролог + эпилог. NG+.

> ОБЯЗАТЕЛЬНОЕ ЯДРО: главный герой ВСЕГДА сражается ДВУМЯ полноценными катанами одновременно. Правая и левая руки анимируются независимо. Никогда не забирать вторую катану.

## 1. СТИЛИСТИКА / АРТ-ДИРЕКШН

### 1.1. Философия стиля
- **Реализм + Ёкай-сюрреализм.** Мир реальный: дерево, солома, камень, железо. Демоны - нарушение реальности: лишний сустав, слишком длинная шея, мясо поверх доспеха.
- **Ваби-саби и грязь.** Никакого чистого фэнтези. Доспехи мятые, клинки со щербинами, солома гнилая, кровь запекшаяся.
- **Контраст:** тишина / взрыв. Пустой бамбуковый лес 2 минуты - потом 20 секунд резни с белой вспышкой Issen.

### 1.2. Цветовая палитра по главам
- **Пролог Ивате:** пепельно-серый `#6B6B6B`, угольно-черный, тлеющий оранжевый `#FF4A00`. Туман.
- **Глава 1 Лес:** глубокий бамбук-зеленый `#1A3A2A`, туманно-молочный, кровь-алая `#A00A1A`.
- **Глава 2 Храм:** гнилое дерево `#4A3520`, болотная вода `#1E3A3A`, золото статуй `#C9A227`, плесень.
- **Глава 3 Снег:** бело-синий `#DDE6F0`, черный доспех, красное хаори героя как единственное теплое пятно.
- **Глава 4 Столица:** фонарно-оранжевый ночью, бумажно-белый днем, фиолетовая скверна Генма `#6A0DAD`.
- **Глава 5 Адзути:** инверсия - черное небо, белый пепел снизу вверх, лава-трещины.

### 1.3. Свет
- Lumen глобальное освещение. Только 1-2 источника: солнце сквозь бамбук (полосы), факелы (мерцание 8-12 Гц), луна (холодный rim-light).
- Души светятся собственным светом (point light с дистанцией 5м) - в темноте бой освещается душами.
- Issen - мгновенная вспышка белого 5000 люмен на 0.15 сек + затемнение окружения на 70%.

### 1.4. Референсы визуала
- Кимоно/броня: фото тосэй-гусоку из музея в Токио, а не аниме.
- Демоны: гравюры Укиё-э + анатомия насекомых.
- Камера в коридорах: фиксированные ракурсы как в Onimusha 1 (дань), в аренах - свободная за плечом.
- **Главный визуальный реф:** приложенные скрины (Onimusha: Way of the Sword-подобная картинка) — см. 1.5.

### 1.5. Референс-борд по скринам (ГЛАВНЫЙ визуальный ориентир)
> Эти 8 скринов — эталон картинки. Если текст GDD противоречит скрину по визуалу, приоритет у скрина. Исключение — механика: у Акиры ВСЕГДА две катаны, даже там, где на рефе одна или копье.

**Общий знаменатель всех скринов**
- Десатурированная холодная база (сине-зеленый туман, мокрый камень, почти черные тени) + **одно теплое пятно** (факел, фонарь, жаровня) или **одно яркое магическое** (белый Issen, синяя перчатка, красная сфера).
- Фотореализм лиц и тканей: поры, щетина, пот, грязь слоями. Ткань тяжелая, мокрая, рваная по краю.
- Демоны — «органика поверх человека»: мокрая черная смола, красные жилы-черви, бумага, кость. Не броня-фэнтези.
- Много частиц в воздухе всегда: пепел, пыль, морось, искры.

## 2. СЮЖЕТ ДЕТАЛЬНО

### 2.1. Мир
1582 год. Хонно-дзи сгорел, Ода Нобунага мертв. Его тело похитила **Курохиме, Даймё Пустоты** - верховный Генма. Она вселяет демона в труп Нобунаги и открывает врата Ёми. Генма вселяются в мертвых самураев, крестьян, животных.

Души убитых не уходят, их можно поглощать. Тот, кто соберет 108 душ и 5 Печатей Зеркала, может запечатать врата.

### 2.2. Герой: Акира Куроганэ, 27 лет
Ученик школы Нитэн Ити-рю (два меча). Не спас отряд в Ивате. Брат Сота добровольно стал Генма ради силы. Акира идет мстить и спасать.

Характер: молчалив, устает, тяжело дышит, вытирает кровь с лица рукавом. Не пафосный, а виноватый.

Внешность (скрины 1, 2, 7): длинные темные спутанные волосы, собраны в низкий хвост, пряди падают на лицо. Щетина, загар, грязь и черная смола Генма на лице. Одежда слоями: темное кимоно, красный рваный жилет-дзимбаори, серая шерстяная накидка-капа с капюшоном для исследования (в бою сползает на плечи). Шрам через левое плечо.

### 2.3. Две катаны - два персонажа
**Правая - АКАЦУКИ (Рассвет), 73.2 см, стихия ОГОНЬ.** Меч отца. Красная сагэо, цуба-солнце (8 лучей). Клинок с хамоном-волной. Тяжелая рубящая.
**Левая - ЁИ (Сумерки), 68.5 см, стихия ТЕНЬ/ЛЕД.** Меч брата. Черно-синяя рукоять, цуба-полумесяц из темной бронзы со вставкой из синего камня (лазурит, слабо светится при поглощении душ — скрин 2). Чуть сильнее изгиб (сори 2.4 см). Быстрая колющая.

Лор-правило: поодиночке - обычные. Скрещенные - ключ от врат. При скрещивании звон как колокол + искра.

Третий элемент: **Онмё-но-Котэ, Перчатка Поглотителя** на левой руке. Серебро и старая бронза, сегменты как чешуя/ребра дракона от запястья до локтя, в ладони — синяя сфера с вихрем. При поглощении по пальцам бегут **синие молнии** (скрин 7). Фиолетовый оставляем только за скверной Генма, чтобы цвета героя и врагов не смешивались. Ею поглощает души (зажать E / R2).

### 2.4. Структура по главам
- **Пролог - Пепел Ивате (30 мин):** обучение: движение, 2 кнопки атаки, первый Issen на соломенном чучеле-Генма, получение перчатки, сожжение деревни. Босса нет, мини-дуэль с братом (скриптовое поражение).
- **Глава 1 - Лес Шепчущих Бамбуков (2 ч):** хоррор, засады Кама-итати, лучники на деревьях. Пазл с водой и водяным колесом. Мини-босс: Сироганэ-самурай №1.
- **Глава 2 - Затонувший Храм Хонган-дзи (2.5 ч):** вода по колено, вертикальность, Мукодзу, Нурэ-онна как загадка-босс. Пазл с зеркалами.
- **Глава 3 - Снежная крепость Курояма (3 ч):** штурм, Тэппо-стрелки, Доро-сумо ломают ворота, стелс-отрезок 10 мин без брони. Босс: Генерал Доро-Хидэ.
- **Глава 4 - Столица Мертвых (2.5 ч):** город, мирные превращаются, Уба-ведьмы воскрешают. Моральный выбор: сжечь квартал с живыми чтобы убить гнездо. Босс: Сота, Падший Брат (полноценная дуэль).
- **Глава 5 - Перевернутый Адзути (3 ч):** замок висит над бездной, гравитация рвется, все типы врагов, финальный забег без сохранений 20 мин. Боссы подряд: Курохиме (3 фазы) -> Нобунага-Генма.
- **Эпилог:** 3 концовки: Путь Меча (убить брата), Путь Души (отдать руку/перчатку ради брата), Путь Пустоты (собрать 108 душ - стать стражем врат).

NPC: Юки (девочка 10 лет, видит души, подсказки), Дзюдзо (кузнец-они, одноглазый, прокачка), Тэнкай (монах-предатель, продает секреты).

## 3. МЕХАНИКИ

### 3.1. Core Loop (60-90 сек цикл)
1. Вход в зону -> смена камеры на кинематографичную.
2. Бой 3-7 врагов (45 сек).
3. Issen-добивания -> пауза тишины.
4. Поглощение душ (зажать кнопку, 3-5 сек, уязвим).
5. Траты душ: открыть дверь-магатама / прокачать / купить онигири.
6. Загадка 2-4 мин.
7. Сохранение у зеркала.
8. Повтор.

### 3.2. Управление (PC + геймпад)
- **ЛКМ / R1:** Атака правой (Акацуки). Рубка дуга 180°, 24-32 урона, медленная (старт 18 фреймов, актив 6, восстановление 22 при 60 fps).
- **ПКМ / R2:** Атака левой (Ёи). Укол 12-16 урона x3, быстрая (старт 10 фреймов, актив 4, восстановление 12).
- **ЛКМ+ПКМ / Треугольник:** Нитэн-удар двумя (крест). 45 урона, тратит 25 выносливости, отбрасывает, ломает блок.
- **Shift / Круг:** Уворот Суриаси. 0.4 сек i-frames. След послесвечения. Идеальный уворот (за 0.12 сек до удара) = слоу-мо 1.2 сек + звук остановившегося сердца.
- **Q / L1 (удерживать):** Блок скрещенными клинками. Поглощает 80% физ. урона спереди 120°. Тратит выносливость. Отбивает стрелы с искрой. Нельзя двигаться.
- **Q + вовремя (за 0.18 сек до попадания) / L1+вперед:** ISSEN. Контрудар с гарантированным расчленением обычного врага. Кулдаун 0.5 сек. Восстанавливает 10 Они.
- **E (удерживать) / Квадрат удерживать:** Поглощение душ. Луч из перчатки, радиус 5/12/20м по уровню перчатки. Герой замедлен на 70%, уязвим. Прерывание = потеря половины сфер.
- **1/2/3 / D-pad:** Смена стоек Тигр / Журавль / Вода.
- **F / L2+R2:** Магия. Акацуки - Огненный серп (20 маны, волна 40 урона + поджог 5/сек 3 сек). Ёи - Лунные цепи (15 маны, заморозка 4 сек).
- **R / R3:** Режим МУСО НИТЭН при полной шкале Они.

Выносливость: 100 ед. Правая -15, левая -7, Нитэн -25, уворот -20, блок-удар -30. Реген 25/сек если стоишь, 12/сек в движении, 0 в поглощении.

Здоровье: 120 HP (прокачка до 180). Лечения только онигири (40 HP) и желтые души (10 HP). Нет авторегена.

### 3.3. Стойки подробно
**ТИГР (атака):** мечи опущены, волочатся с искрами. +30% урон, +20% скорость правой, нельзя Issen, уворот на 20% короче. Анимация: низкий присед, дыхание тяжелое, экран чуть краснеет по краям. Для брони и боссов.
**ЖУРАВЛЬ (баланс, дефолт):** правая вверх за головой, левая назад. Доступен Issen, нормальный урон. Для дуэлей 1х1.
**ВОДА (скорость/защита):** клинки скрещены перед лицом. -20% урон, +40% скорость левой, круговая атака 360° левой, идеальна против стаи и лучников. Шаг назад вместо уворота (длиннее).

Переключение - мгновенно, с 0.2 сек вспышкой стойки и звуком (Тигр - рык, Журавль - крик птицы, Вода - плеск).

### 3.4. Таблица комбо (фреймы при 60 fps)
- П-П-П: Двойная рубка -> разворот с обеими (3-й удар 50 урона, отброс 6м). Окно ввода 20 фреймов.
- Л-Л-Л-П: Шквал 3x14 -> крест 45. Подброс легкого врага.
- П-Л-П: Рубка -> укол в открытие -> рубка с разворотом. Бонус +15% если второй удар в спину.
- В прыжке П+Л: Крест Падающей Луны. Ударная волна 3м, 35 урона + нокдаун.
- Спринт + П: Набегающий рубящий с плеча, 38 урона, ломает щит.
- Спринт + Л: Прокат под ногами + укол вверх.
- После идеального уворота + П: Автоматический Issen-рывок к врагу (телепорт-шаг 5м).

### 3.5. Шкала ОНИ и МУСО НИТЭН
Набор: Issen +15, идеальный уворот +10, поглощение 5 душ +10, получение урона -20.
Полная 100 = можно активировать на 20 сек: за спиной призрачные руки с еще 2 катанами (итого 4 клинка визуально), скорость x1.5, каждый удар поджигает+замораживает, урон x1.5, неуязвимость к прерыванию, музыка - гитара+тайко, экран темнеет, герой в цвете, снег/пепел летят вверх. После - истощение 5 сек (урон -30%).

### 3.6. Души (валюта)
- **Красные:** опыт/деньги. 1 обычный враг = 5-12. Прокачка оружия, покупка.
- **Синие:** мана. 1 враг = 3-8. Тратятся на магию.
- **Желтые:** здоровье. Автоподбор при <50% HP, иначе лежат 10 сек.
- **Фиолетовые (редкие, с боссов/ведьм):** очки Они + открытие дверей Пустоты.
Механика жадности: если не поглотить за 15 сек, души чернеют и вселяются обратно в труп - враг воскресает с +50% HP (как в Onimusha). Риск/награда.

### 3.7. Прокачка у кузнеца Дзюдзо
- Акацуки ур.1-5: урон 28->34->41->49->58. Визуал: трещины огня больше, на 5 ур. клинок постоянно тлеет. Цена: 500/1200/2500/5000 красных.
- Ёи ур.1-5: урон 14->17->21->26->32 (за удар, ударов 3). Визуал: иней -> изморозь -> снег на цубе. Цена аналогично.
- Перчатка ур.1-3: радиус 5м->12м->20м, скорость втягивания x1->x1.5->x2. Цена: 800/2000/4000.
- Здоровье: +15 HP за 1000 душ, max 180.
- Выносливость: +10 за 800, max 140.

### 3.8. Предметы
- Онигири (40 HP), 3 слота, пополнение у зеркал.
- Пороховая бомба (60 урона по площади + стан).
- Яд Нури (30 сек +8 урона к каждой атаке, зеленые следы).
- Зеркало-телепорт (возврат к последнему сохранению, 1 раз).
- Талисман Тишины (враги не слышат 60 сек для стелса).
- Хаори (косметика из ларцов, скрин 5): базовое серое, «Лазурная волна» (бледно-голубое с золотым узором), красное отцовское и др.

### 3.9. Сохранения и сложность
Сохранение только у зеркал-сакра (как печатные машинки в Resident Evil). Зеркал мало (1-2 на главу). Сохранение тратит 1 синюю душу.
Сложности: Ронин (легко, окно Issen 0.25 сек, враги -30% HP), Самурай (норма, окно 0.18 сек), Демон (хард, окно 0.12 сек, воскрешение душ за 8 сек). После смерти - возрождение у зеркала, души на месте смерти (как в Souls, 1 шанс подобрать).

## 4. МОДЕЛЬКИ / АССЕТЫ - ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### 4.1. Герой Акира
- **Поликаунт:** 85-110к треугольников (hero), LOD0-LOD3 (110к/60к/25к/8к).
- **Скелет:** UE5 Manny + 2 дополнительных IK-костя для левой руки-меч (независимый слой), 4 пальца на перчатке с отдельной физикой.

## 16. КОД КОНТРОЛЛЕРА ДВУХ МЕЧЕЙ (псевдо C++ для UE5)

```cpp
// DualCombatComponent.h - фрейм-дата, окна Issen, слои анимации
UCLASS()
class NITEN_API UDualCombatComponent : public UActorComponent {
  GENERATED_BODY()
public:
  UPROPERTY(EditAnywhere) float IssenWindow = 0.18f; // Ронин 0.25 / Самурай 0.18 / Демон 0.12
  UPROPERTY(EditAnywhere) float RightStartup = 18.f/60.f, RightActive=6.f/60.f, RightRecover=22.f/60.f;
  UPROPERTY(EditAnywhere) float LeftStartup = 10.f/60.f, LeftActive=4.f/60.f, LeftRecover=12.f/60.f;
  float Stamina = 100.f;
  int32 Stance = 1; // 0 Тигр, 1 Журавль, 2 Вода
  void TryRightAttack(); void TryLeftAttack(); void TryNiten();
  bool TryIssen(float EnemyAttackTime); // если EnemyAttackTime - Now < IssenWindow -> успех
  void PerfectDodge(); // i-frames 0.4 сек, slow-mo 1.2 сек
  void AbsorbSouls(bool bHolding); // магнит душ, радиус по уровню перчатки
};
// Логика Issen:
// 1. Враг начинает замах -> Broadcast AttackStarted(Time+HitMoment)
// 2. Игрок жмет Q+вперед: если HitMoment - Now <= IssenWindow -> HitStop 0.12сек, WhiteFlash, PlayMontage Issen_ПП/ЛЛ по углу, Enemy.Die(Dismember)
// 3. Иначе - обычный блок: Stamina -=30, камера трясется
// Правая и левая руки - два отдельных AnimMontage слоты: UpperRight, UpperLeft. Нитэн - FullBody.
```

Чеклист анимационных нотифаев: `Trail_On` на active-фреймах, `HitStop` на попадании, `SoulSpawn` на смерти, `Footstep` + `Cloth` всегда.
