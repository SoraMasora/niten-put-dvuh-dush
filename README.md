# NITEN: Путь Двух Душ

3D action-игра (Three.js) по GDD «Нитэн: Путь двух душ», вдохновлённая Onimusha: Way of the Sword.
Герой Акира с двумя катанами (Акацуки и Ёи), перчатка душ, Иссэн, стойки, Генма, босс Сота.

## Структура
| Папка | Что внутри |
|---|---|
| `docs/` | GDD |
| `game/src/` | исходники 3D-игры (ES-модули, Three.js) |
| `game/build.sh` | сборка (esbuild) |
| `blender/` | Python-скрипты Blender, генерирующие модели (`.blend` + `.glb`) |
| `dist/` | собранные версии игры (открыть `index.html`) |
| `legacy-2d/` | первая 2D-версия |

## Управление
WASD — движение, мышь — камера (клик — захват мыши), ЛКМ/ПКМ — удары Акацуки/Ёи, ЛКМ+ПКМ — удар креста,
Shift — уворот, Tab — захват цели, H — онигири.

## История версий
- v0.1 — 2D canvas-прототип (`legacy-2d/`)
- v0.3 — 3D-версия на Three.js с примитивными моделями
