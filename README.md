# NITEN: Путь Двух Душ

3D action-игра (Three.js) по GDD «Нитэн: Путь двух душ», вдохновлённая Onimusha: Way of the Sword.
Герой Акира с двумя катанами (Акацуки и Ёи), перчатка душ, Иссэн, стойки, Гэнма, босс Сота.

**Играть:** откройте `dist/index.html` в браузере (Chrome/Edge/Firefox с WebGL2). Работает и с диска, и через GitHub Pages.

## Модели (Blender)
Все модели генерируются кодом в Blender (`bpy` 5.2) — скрипты в `blender/`:

| Скрипт | Модели |
|---|---|
| `chars.py` | Герой в образе Миямото Мусаси (сине-серое кимоно с широкими рукавами, широкое серое оби с узлом и свисающими концами, тёмная хакама, дикие волосы с растрёпанным пучком и выбившимися прядями, щетина, шрам, густые брови, перчатка Они, дайсё в оби); старый доспешный вариант Акиры (лакированный до из пластин кодзанэ, кусадзури, содэ, хакама, кяхан, сунэатэ, вараджи, плащ с капюшоном, хатимаки, пучок волос, перчатка Они со светящимися жилами, ножны), Сота (длинные волосы, рога 2-й фазы, красные глаза) |
| `swords.py` | Катаны: изогнутый клинок с синоги, долом бо-хи, ёкотэ и хамоном (гуномэ/тёдзи, ниэ, боси), хабаки, цуба с ободом мими, прорезями и рельефом (лучи солнца у Акацуки, волны у Ёи), мэкуги, сэппа, фути/касира, оплётка ито поверх кожи ската, мэнуки, лазурит Ёи; ножны |
| `demons.py` | Гэнма-копейщик (смоляное тело, рёбра, шипы, красные жилы, дзингаса, яри), Хитоцумэ Гаса (зонт-каса с костяной бахромой, один глаз), Кама-итачи (серпы), Лучница-рокурокуби |
| `props.py` | Каменный фонарь касуга-доро, тории с симэнавой, колокол бонсё |
| `env.py` | Окружение: минка с соломенной вальмовой крышей (целые и сгоревшие), сёдзи, заборы, пугала, телега, бочка, колодец, обломки с углями; бамбук с узлами и листвой, мшистые камни, трава, хокора; киноварные столбы с кронштейнами, стены цуйдзи с черепицей, фасад хондо, колокольня сёро, жаровни кагариби; PBR-земля (пепел, мох, каменные плиты) |
| `anim.py` | Анимации героя: ключевые позы -> Actions на суставах `AK__J_*` (кватернионы, интерполяция SINE/EXPO/BACK), NLA-дорожки по клипам, IK руки к рукояти/ножнам, мечи `AK__J_swR/swL` (ножны / скольжение / рука / полёт). Клипы: обнажение, вложение в ножны с тибури, idle-подбрасывание катаны, атаки R1/R2/R3/L1/L2/L3/N/X. Запекается в `game/src/anims.js` |
| `tex.py` | Процедурные PBR-текстуры (ткань, кодзанэ, кожа, волосы, сталь, хамон, смола, солома, дерево, камень, кость, бумага) |

Модели сегментированы по суставам игрового рига (`PREFIX__часть__деталь`). Юбка хакамы, кусадзури и концы оби (детали `sk_*`) скиннятся на GPU к бёдрам и ногам, чтобы ноги не проходили сквозь ткань.

## Сборка
```bash
pip install bpy==5.2.2 numpy pillow   # Blender как Python-модуль (Python 3.13)
npm install
bash game/build.sh                     # модели -> .blend + .glb -> meshopt -> dist/
```
Результат: `blender/out/niten_characters.blend` (все модели, коллекции по персонажам), `blender/out/niten_assets.glb`, `dist/index.html`.
`SKIP_MODELS=1 bash game/build.sh` — пересобрать только код.

## Структура
| Папка | Что внутри |
|---|---|
| `docs/` | GDD |
| `blender/` | генераторы моделей и текстур |
| `tools/optimize.mjs` | оптимизация GLB (weld, simplify, квантование, meshopt) |
| `game/src/` | исходники игры (`assets.js` — загрузка моделей) |
| `dist/` | собранная игра (`index.html` + `assets/partNN.js` — модели в base64) |
| `legacy-2d/` | первая 2D-версия |

## Управление
WASD — движение (C — шаг), мышь — камера (клик — захват мыши), ЛКМ/ПКМ — удары Акацуки/Ёи, ЛКМ+ПКМ — удар креста,
Shift — уворот, Tab — захват цели, H — онигири, P — обнажить/вложить мечи (атака обнажает сама), Esc — пауза.

- v0.5 — исправлен HUD; новые походка/бег (шаг по длине шага, сгиб колен, покачивание таза, наклон), режим шага (C), idle-анимации (дыхание, перенос веса, осмотр, расслабленная стойка с опущенными клинками), подёргивания Гэнмы; предкомпиляция шейдеров при загрузке; GPU-дождь с рябью на лужах, молнии и гром, звук дождя; детализированные катаны; локации из Blender (`env.py`)
