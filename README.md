# NITEN: Путь Двух Душ

3D action-игра (Three.js) по GDD «Нитэн: Путь двух душ», вдохновлённая Onimusha: Way of the Sword.
Герой Акира с двумя катанами (Акацуки и Ёи), перчатка душ, Иссэн, стойки, Гэнма, босс Сота.

**Играть:** откройте `dist/index.html` в браузере (Chrome/Edge/Firefox с WebGL2). Работает и с диска, и через GitHub Pages.

### Внешние модели (v0.10, `blender/ext/`)
Готовые модели (Sketchfab и др., исходники не хранятся в git — положить в `$NITEN_SRC`, по умолчанию `/data/src`) обрабатываются в Blender и собираются в `blender/out/niten_ext.glb`:

| Персонаж / объект | Модель | Что сделано в Blender |
|---|---|---|
| Акира (герой) | `mysterious-ronin.zip` | масштаб 1.8 м, децимация до ~36k, скин на 13 суставов рига игры (`XS__hero`) |
| Сота (брат, босс) | `samurai-character.zip` (FBX + текстуры) | сборка материалов из TGA, удалена встроенная катана, скин (`XS__sota`); во 2-й фазе снимает маску, появляются рога |
| Куро-асигару (ронины) | `enemie.zip.zip` (FBX) | скин (`XS__ronin`), в руке яри |
| Юми-они (лучники) | `monster_skeleton_archer` | скин (`XS__archer`), лук в левой руке, поза натяжения |
| Кама-итати (бамбуковый лес) | `bunny_rat_monster.glb` | свой скелет; клипы `KM_idle/run/crouch/leap/hit` (NLA), в игре — AnimationMixer |
| Самураи Забытого дома | `samuraienemy.glb` | веса родного рига перенесены на 13 суставов (`XS__musha`), также в витринах |
| Тётин-обакэ (фонари) | `pumpkin_monster.glb` | центрирование, вершинные цвета (`PK__body`) |
| Кагэмару, Страж Дома (босс) | `dark_samurai_shadow_warrior.glb` | поворот, вырезан запечённый клинок, скин (`XS__boss`) |
| Катаны Акиры + ножны | `katana.glb` | ось клинка → +Z, гарда/кончик (`KN__sword`, `KN__saya`, `KN__TIP`) |

Скрипты: `cfg.py` (источники, высота, бюджет треугольников), `prep.py` (импорт, чистка, текстуры, масштаб, децимация), `rigcfg.py` + `rig.py` (ориентиры суставов, расчёт весов по расстоянию до костей с диффузией по рёбрам, поза покоя рига игры), `bunny.py` (клипы кролика), `build_ext.py` (экспорт GLB, текстуры 512–1024 JPEG). Анимации героя/Соты/самураев — те же клипы и позы рига игры (`anims.js`, `POSE`), переданные новым моделям через GPU-скиннинг; при гибели скин делится по поясу без растяжения. Хитоцумэ Гаса остаётся процедурной моделью.

Модели сегментированы по суставам игрового рига (`PREFIX__часть__деталь`). Юбка хакамы, кусадзури и концы оби (детали `sk_*`) скиннятся на GPU к бёдрам и ногам, чтобы ноги не проходили сквозь ткань.

### Локации (v0.12, `blender/ext/locs.py`)
Готовые локации (исходники в `$NITEN_SRC/loc`, не в git) обрабатываются в Blender: `python3 blender/ext/locs.py <village|sagano|scifi|portal|manor|merge>` — импорт, запекание трансформов, масштаб, выравнивание земли (земля игровой зоны точно на y=0, окрестности сглаженно), размещение старта и ворот, навигационная сетка (клетка 0.4 м, отступ от стен, обрывы, связность от старта) и высоты для камеры, экспорт. `merge` собирает `blender/out/niten_loc.glb` (WebP-текстуры через `TEX=webp node tools/optimize.mjs`) и генерирует `game/src/gN.js` (nav-сетки).

| Локация | Модель |
|---|---|
| Пролог «Горящая деревня» | `village.glb` (пожары, угли, туман) |
| Глава 1 «Бамбуковый лес» | `sagano_bamboo_forest.glb` (фонари и святилище вдоль дороги) |
| Двор колокола (дуэль с Сотой) | `sci-fi_japan_environment.glb` + колонны, колокольня, жаровни |
| Порталы между локациями | `magic_portal.glb` (кольцо + свечение) |
| Усадьба «Забытого дома» снаружи | `manor.glb` (ступени, двустворчатая дверь) |

Игрок и враги ходят по nav-сетке (`game/src/gL.js`: скольжение вдоль стен, обход препятствий по полю расстояний, проверка видимости); волны появляются в свободных клетках в поле зрения на 6–13 м; камера не заходит в дома. Ограничения: деревня в европейском стиле, как в исходной модели; стрелы не сталкиваются с домами.

### v0.13: листва, анимации взаимодействий, одна катана, Кагэмару, звук (`blender/anim13.py`, `blender/ext/foliage.py`, `tools/sfx.py`)
- **Листва**: `python3 blender/ext/foliage.py` (вызывается из `build.sh` после `locs.py merge`) — у карточек травы/листвы деревни фон вырезается хромакеем в альфу (апскейл 2×), бинарная альфа переводится в режим MASK, материалы двусторонние: больше нет непрозрачных зелёных прямоугольников.

- **Сундук**: ключ всё время в правой руке героя (вставляется, поворачивается и остаётся в замке), крышка идёт за ладонями, предмет берётся рукой со дна. **Записка и ключ дома**: герой подходит, приседает, берёт предмет пальцами и держит (записку — у груди обеими руками). Предметы крепятся к кисти (`handXf`, `P.csClip`, `P.csPost`).
- **Путь одной катаны** (после гибели Ёи): ЛКМ ×4 — цепь «кэса → гяку-кэса → ёко-нами (широкая дуга) → цуки-пронзание по линии»; ПКМ — джеб/апперкот перчаткой Они (подбрасывает) и копит «Пламя Они» (до 3 огненных ударов ЛКМ: +35 % урона, поджог); ЛКМ+ПКМ — «Кулак Они» о землю (удар по кругу 3.2 м, ударная волна); удержание ЛКМ — заряд «Дзан» (≈0.7 с) и рывок-разрез на 3–6.5 м с неуязвимостью и следом. Багрово-золотой след клинка, огненный при пламени.
- **Кагэмару** (`updKage`): удар о-дати в пол с обманной задержкой и волной по полу (перепрыгнуть), круговой низкий взмах (прыжок/уворот, фиолетовый блик), три укола с шагами, шаг-тень за спину и удар наотмашь (синий блик), рёв во второй фазе (отталкивает).
- **Звук** (`tools/sfx.py` → `blender/out/sfx`, `niten_sfx.json`): сэмплы Kenney (CC0) + синтез (кото, тайко, колокола) — удары, лязг, урон, подбор, хил, появление врагов, победа, телепорт, удары перчатки, заряд, замок, крышка, бумага; шины SFX/реверб. **Музыка**: приглушённые темы по локациям (пролог, лес, двор колокола, дом) и отдельная тема боя с Кагэмару (lowpass, кроссфейд, приглушение в паузе/инвентаре/репликах).

## Сборка
```bash
pip install bpy==5.2.2 numpy pillow   # Blender как Python-модуль (Python 3.13)
npm install
bash game/build.sh                     # модели -> .blend + .glb -> meshopt -> dist/
```
Результат: `blender/out/niten_characters.blend` (все модели, коллекции по персонажам), `blender/out/niten_assets.glb`, `dist/index.html`.
`SKIP_MODELS=1 bash game/build.sh` — пересобрать только код (используются готовые `blender/out/*.opt.glb`). `SKIP_EXT=1` — не пересобирать внешние модели, `SKIP_KAK=1` — деревню (v0.14), `SKIP_GREEN=1` — «Зелёную пустошь» (v0.16), `SKIP_TEMPLE=1` — храм «Путь» (v0.17), `SKIP_SFX=1` — звуковой банк.
Внешние модели: `python3 blender/ext/prep.py` → `python3 blender/ext/rig.py` → `python3 blender/ext/build_ext.py` (вызывается из `build.sh`).

## Управление
- **F2** или **`** — админ-панель (читы, главы, враги, предметы, телепорт)
WASD — движение (C — шаг), мышь — камера (клик — захват мыши), ЛКМ/ПКМ — удары Акацуки/Ёи, ЛКМ+ПКМ — удар креста,
Shift — уворот, Tab — захват цели, H — онигири, P — обнажить/вложить мечи (атака обнажает сама), Esc — пауза,
I — инвентарь (ЛКМ — выбрать, перетаскивание — переложить, ПКМ/двойной клик — использовать, перетащить за окно/Delete — выбросить), X — взаимодействие (подобрать, открыть сундук, осмотреть тайник, открыть дверь), M — карта мира: свободный переход в любую открытую локацию (в доме — план усадьбы, в деревне — план деревни по K).
В храме «Путь» X у алтаря — табличка и выбор катаны (второй X — подтвердить). В концовке Enter — главное меню.
X у старого колодца в центре «Родной деревни» — прыжок в колодец и переход в «Зелёную пустошь». На пустоши X — взять предмет / положить в чашу / забрать из чаши, прочитать записку на доске, шагнуть в портал (после решения загадки).
После засады в доме Ёи сломана — путь одной катаны: ЛКМ ×4 — цепь, ПКМ — перчатка Они (копит пламя), ЛКМ+ПКМ — Кулак Они, удерживать ЛКМ — Дзан.
